# Movie Financial Analysis

Analyzed a movie dataset using SQL, Python, and Excel to explore financial performance, ROI, genre trends, runtime, release year, and production company performance.

## Tools Used

- SQL
- Python
- Excel

## What I Analyzed

- Revenue and budget performance
- Return on investment (ROI)
- Genre-level ROI
- Runtime and ROI
- Release year trends
- Production company performance
- Correlation between budget, revenue, popularity, and ROI

## Key Findings

- Budget and revenue had a strong positive correlation of about 0.73.
- Some genres showed much higher average ROI than median ROI, suggesting that a few major outliers can heavily affect averages.
- Production companies varied significantly in median ROI.
- Comparing median and average ROI helped provide a more realistic view of typical movie performance.
